# API Finance Control #

 **Status**: In development

##  Functionalities
- User registration.
- Financial transaction record.
- Classify transactions by type and category..
- View and group transactions by date.
- Data persistence in database PostgreSQL.
- structure designed to facilitate future integrations.

##  Technologies
- Java 17
- Spring Boot
- JPA / Hibernate
- PostgreSQL
- Lombok

## How to use
```bash
# Clone the repository
git clone https://github.com/iochem/finance-control-api.git

# Configure the PostgreSQL database and  set the properties in the application.properties file

# Run the application
./mvnw spring-boot:run

# Access the API by endpoint configured (ex: http://localhost:8080)
